5. Creating Updated Objects with map()

Existing objects-ஐ mutate செய்யாமல் updated objects உருவாக்கும் immutable pattern-க்கும் map() மிகவும் useful. 


const users = [
    { name: "Kesava", age: 30 },
    { name: "Arun", age: 28 }
];

const updatedUsers = users.map(user => {

    if (user.name === "Kesava") {
        return {
            ...user,
            age: 31
        };
    }

    return user;
});

Arun → existing object returned

↓

[
    { name: "Kesava", age: 31 },
    { name: "Arun", age: 28 }
]
Important connection: map() + spread syntax { ...user } → existing object-ஐ mutate செய்யாமல் updated object உருவாக்கலாம்.
6. map() Must Return the Result You Want

const numbers = [1, 2, 3];

map() callback ஒவ்வொரு element-க்கும் ஒரு value return செய்ய வேண்டும். Braces { } பயன்படுத்தி return எழுதவில்லை என்றால், callback implicitly undefined-ஐ return செய்யும்.

filter()

filter() என்பது condition-ஐ satisfy செய்யும் elements-ஐ மட்டும் தேர்வு செய்து ஒரு new array உருவாக்கும் method.

Simple Definition:
filter()
↓
Check each item
↓
Keep / Remove
↓
New Array
map()
Transform each item
↓
"What should this item become?"
filter()
Select items
↓
"Should I keep this item?"
1. Basic Example

const numbers = [1, 2, 3, 4, 5];

const result = numbers.filter(num => num > 3);

console.log(result);
1 > 3 → false → remove
2 > 3 → false → remove
3 > 3 → false → remove
4 > 3 → true → keep
5 > 3 → true → keep

↓
[4, 5]
Output: [4, 5]
2. The Callback Must Return a Condition

numbers.filter(num => num > 3);
callback return value
↓
true → keep the original item
false → remove the item
Key Rule: filter() callback-ன் return value output value-ஐ உருவாக்காது. அது அந்த item-ஐ keep செய்யலாமா வேண்டாமா என்பதை decide செய்கிறது.
3. filter() Does Not Modify the Original Array

const numbers = [1, 2, 3, 4, 5];

const result = numbers.filter(num => num > 3);

console.log(numbers);
console.log(result);
Original
[1, 2, 3, 4, 5]
New Array
[4, 5]
Important: filter() original array-ஐ modify செய்யாது. ஒரு new array உருவாக்கும்.

10. Truthy / Falsy Behavior

filter() strictly true அல்லது false மட்டும் கேட்பதில்லை. Callback return value truthy அல்லது falsy என்ற அடிப்படையில் decision எடுக்கிறது. 


const numbers = [1, 2, 3];

const result = numbers.filter(
    num => num * 0
);

console.log(result);
num = 1 → 1 × 0 = 0 → falsy
num = 2 → 2 × 0 = 0 → falsy
num = 3 → 3 × 0 = 0 → falsy

↓
[]
Why?

Arrow function implicit return மூலம் 0 return செய்கிறது. 0 falsy என்பதால் எந்த element-மும் keep ஆகாது.

reduce()

reduce() என்பது array-ல் இருக்கும் elements-ஐ ஒன்றன்பின் ஒன்றாக process செய்து, அவற்றை ஒரு final result-ஆக combine செய்யும் method.

Important: Final result ஒரு number மட்டும் இருக்க வேண்டிய அவசியம் இல்லை. அது number, string, object, array, boolean போன்ற எந்த value-ஆகவும் இருக்கலாம்.
Array
↓
Process one item
↓
Carry result forward
↓
Process next item
↓
Continue...
↓
Final Result
1. Simplest Example — Sum

const numbers = [10, 20, 30, 40];

const total = numbers.reduce((acc, num) => {
    return acc + num;
}, 0);

console.log(total);
Output: 100

இங்கே acc என்பது running result.

Initial acc = 0

10 → 0 + 10 = 10
20 → 10 + 20 = 30
30 → 30 + 30 = 60
40 → 60 + 40 = 100

Final
100
reduce() Syntax
array.reduce((accumulator, currentValue) => { ... }, initialValue)
accumulator

Previous iteration-ல் கிடைத்த result. அடுத்த iteration-க்கு carry ஆகும்.

currentValue

Current iteration-ல் process செய்யப்படும் array element.

initialValue

Accumulator ஆரம்பிக்கும் starting value.

So: 

numbers.reduce(
    (acc, num) => acc + num,
    0
);

acc ஆரம்பத்தில் 0. அந்த 0 ஒவ்வொரு iteration-லும் மீண்டும் starting value ஆகாது. அது first starting value மட்டும்.

Compare first characters:
1 < 2 < 3 < 4
Lexicographical Order

Dictionary-ல் words எப்படி order செய்யப்படுகிறதோ, அதுபோல character-by-character compare செய்வது.

13. slice() vs splice()

              SLICE                          SPLICE
────────────────────────────────────────────────────────────
Purpose       Take a portion                Modify array

Syntax        (start, end)                  (start, deleteCount,
                                             item1, item2, ...)

Original      ❌ unchanged                  ✅ mutated

Return        Selected portion              Removed elements

One argument  Start → end                  Start → delete to end

Negative      Count from right              Count from right
slice()
TAKE
↓
New array
↓
Original unchanged ✅

slice(start, end)

splice()
MODIFY
↓
Remove / Add / Replace
↓
Original mutated ⚠️

splice(start, deleteCount, ...items)

Final Golden Rule:
slice → take a portion → original unchanged
splice → modify original → remove/add/replace

splice return value = removed elements
splice(start) = delete from start to end
splice() = no change + returns []

Array Method Chaining

Method chaining என்றால், ஒரு array method-ன் result-ஐ அடுத்த method-க்கு input-ஆக பயன்படுத்துவது.

Simple Mental Model:
Array
↓
Method 1
↓
Result
↓
Method 2
↓
Final Result
1. Simple Example

const numbers = [1, 2, 3, 4, 5, 6];

const result = numbers
    .filter(num => num % 2 === 0)
    .map(num => num * 10);

console.log(result);
Execute from Top to Bottom

↓
[1, 2, 3, 4, 5, 6]

filter(num => num % 2 === 0)
↓
Keep even numbers
↓ [2, 4, 6]
[2, 4, 6]
↓
map(num => num * 10)
↓
2 → 20
4 → 40
6 → 60

[20, 40, 60]
Final Output: [20, 40, 60]
2. Common Real-World Example

Suppose users-ல் age 30 அல்லது அதற்கு மேல் உள்ளவர்களின் names மட்டும் வேண்டும்.

    { name: "A", age: 20 },
    { name: "B", age: 35 },
    { name: "C", age: 28 },
    { name: "D", age: 40 }

    .map(user => user.name);

3. Chaining Is Not Magic

இந்த chained code: 


const result = numbers
    .filter(num => num > 10)
    .map(num => num * 2);

Conceptually இதே code: 


const filtered = numbers.filter(
    num => num > 10
);

const result = filtered.map(
    num => num * 2
);
Important: Chained version என்பது separate steps-ஐ compact-ஆக எழுதும் syntax.
numbers
↓
filter()
↓ filtered array
↓

↓ final array
4. You Can Chain More Than Two Methods

const numbers = [1, 2, 3, 4, 5, 6];

const result = numbers
    .filter(num => num % 2 === 0)
    .map(num => num * 10)
    .filter(num => num > 20);

↓

↓ [2, 4, 6]

Chain means:
One method's result → becomes the next method's input.

6. Method Chaining with reduce()

const numbers = [1, 2, 3, 4];

const result = numbers
    .filter(num => num % 2 === 0)
    .reduce((acc, num) => acc + num, 0);

console.log(result);
[1, 2, 3, 4]
↓
filter even
↓ [2, 4]

reduce()
↓
0 + 2 = 2
2 + 4 = 6

6
Why does the chain end here?

இந்த particular reduce() number-ஐ final result-ஆக return செய்கிறது. அது array அல்ல. அதனால் அடுத்த normal array method-ஐ chain செய்ய முடியாது.

But one important nuance: reduce() எப்போதும் chain-ஐ stop செய்யும் என்று நினைக்கக்கூடாது. Accumulator-ஆக ஒரு array-ஐ உருவாக்கி return செய்தால், reduce()-ன் result ஒரு array ஆக இருக்கலாம்; அப்போது array methods-ஐ தொடர்ந்து chain செய்யலாம்.
