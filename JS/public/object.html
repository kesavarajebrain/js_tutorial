Objects

01. What is an Object?

JavaScript-ல் Object என்பது related information-ஐ ஒரே இடத்தில் organize பண்ணும் ஒரு data structure. 


const person = {
    name: "Kesava",
    age: 30,
    city: "Chennai"
};
person
│
├── name → "Kesava"
├── age → 30
└── city → "Chennai"
Tamil Mental Model:

Object = related data-வுக்கான ஒரு container.

02. Why do we need Objects?

const name = "Kesava";
const age = 30;
const city = "Chennai";

Data குறைவாக இருந்தால் இது okay.

Application-ல் 100 users இருந்தால்: 100 names, 100 emails, 100 ages, 100 cities... என்று separate variables manage செய்வது difficult. 

const user = {
    name: "Kesava",
    age: 30,
    city: "Chennai",
    email: "kesava@example.com"
};
Simple Rule: One entity → one object

06. Methods

Object-க்குள் function வைத்தால், அந்த function-ஐ பொதுவாக method என்று சொல்வோம். 


const person = {
    name: "Kesava",

    greet: function () {
        console.log("Hello");
    }
};

Modern JavaScript-ல் shorthand syntax: 


const person = {
    greet() {
        console.log("Hello");
    }
};
Remember: Object property-ன் value ஒரு function ஆக இருந்தால், அதை commonly method என்று சொல்வோம்.

Convert Obj to a Array 


        let convertObj = Object.keys(person);

        (output): 
                  0: "age"

Object Entries


        let objEntries = Object.entries(person);
        console.log(objEntries)

        Output :
        0:  ['age', 25]
        1:  ['address', 'chennai']      Each entry or row will separated by an array!
        2:  ['info', {…}]
