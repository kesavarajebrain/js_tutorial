Objects

01. What is an Object?

JavaScript-ல் Object என்பது related information-ஐ ஒரே இடத்தில் organize பண்ணும் ஒரு data structure. 


const person = {
    name: "Kesava",
    age: 30,
    city: "Chennai"
};
person
│
├── name → "Kesava"
├── age → 30
└── city → "Chennai"
Tamil Mental Model:

Object = related data-வுக்கான ஒரு container.

14. Dynamic Properties

Property name ஒரு variable-லிருந்து வரும்போது, அதை dynamic property என்று சொல்லலாம். 


const key = "city";

const user = {
    name: "Kesava",
    age: 30
};

user[key] = "Chennai";

console.log(user);
key
↓
"city"
↓
user[key]
↓
user["city"]
↓
city → "Chennai"
Why is this called Dynamic?

Property name-ஐ code-ல் நேரடியாக எழுதாமல், ஒரு variable மூலம் runtime-ல் தீர்மானிக்கிறோம்.

20. Object References

இப்போது JavaScript Objects-ல் மிகவும் முக்கியமான concept: Object Reference.

Important Question:

user-க்கு {} பயன்படுத்தி object create செய்தோம். ஆனால் person-க்கு {} பயன்படுத்தவில்லை. அப்படியானால் person எப்படி object-ஐ refer செய்கிறது?

Answer:

person ஒரு புதிய object-ஐ create செய்யவில்லை.
அது user தற்போது வைத்திருக்கும் same object reference-ஐ பெறுகிறது.

21. Primitive vs Reference Values

இப்போது மிகவும் முக்கியமான difference: Primitive Value vs Reference Value.

Example A — Primitive Value

let a = 10;
let b = a;

b = 20;

console.log(a);
console.log(b);
a → 10
b → 10

b = 20
↓
a → 10
b → 20
Output:
10
20
Why didn't a change?

10 என்பது ஒரு primitive value. b = a என்றபோது, b தனக்கென அந்த value-ஐப் பெற்றுக்கொண்டது. பின்னர் b = 20 செய்தாலும், a மாறாது.

Primitive Assignment

a = 10
↓
b = a
↓
a → 10
b → 10

Separate values
Now Compare an Object

let a = {
    value: 10
};

let b = a;

b.value = 20;

console.log(a.value);
console.log(b.value);
a ──────┐
        ↓
     OBJECT
     value: 10
     ↑
b ──────┘
Output:
20
20
Why did a.value also become 20?

a மற்றும் b இரண்டும் same object reference-ஐ வைத்திருக்கின்றன.
அதனால் b.value = 20 என்றால், அதே object-ன் property மாற்றப்படுகிறது.

Reference Assignment

a → 📦 OBJECT
b → 📦 SAME OBJECT

b.value = 20
↓
SAME object changes
↓
a.value → 20
b.value → 20
