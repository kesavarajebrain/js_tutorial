DOM & Browser Events

1. What is DOM?

DOM stands for Document Object Model. நாம் HTML எழுதும்போது, Browser அந்த HTML-ஐ parse செய்து ஒரு tree-like object structure உருவாக்குகிறது. இதைத்தான் DOM என்கிறோம். JavaScript மூலம் இந்த structure-ஐ access மற்றும் modify செய்ய முடியும்.

HTML 
<h1 id="title">Hello World</h1>
<button id="clickBtn">Click Me</button>
JavaScript – Modify DOM 
const title = document.getElementById("title");

title.textContent = "Welcome!";
Heading text changes from "Hello World" to "Welcome!".
2. What are Browser Events?

User webpage-ல் ஏதாவது action செய்யும்போது Browser ஒரு Event உருவாக்குகிறது. JavaScript மூலம் அந்த event-ஐ listen செய்து அதற்கான action-ஐ execute செய்யலாம்.

Event When does it occur?
click User element-ஐ click செய்யும்போது
input Input value மாறும்போது
change Value change commit ஆகும்போது (element-ஐப் பொறுத்து)
submit Form submit செய்யப்படும்போது
keydown Keyboard key press செய்யும்போது
mouseover Pointer element மீது வரும்போது
3. addEventListener()

ஒரு element-ல் குறிப்பிட்ட event நடந்தால், அதற்கான callback function execute ஆக வேண்டும் என்று addEventListener() பயன்படுத்துகிறோம்.

HTML 
<button id="clickBtn">Click Me</button>

<p id="message">Waiting...</p>
JavaScript 
const button = document.getElementById("clickBtn");
const message = document.getElementById("message");

button.addEventListener("click", function() {
    message.textContent = "Button clicked!";
});
**Execution flow**
  1. getElementById() மூலம் DOM elements-ஐ access செய்கிறோம்.
  2. addEventListener() மூலம் click event listener register செய்கிறோம்.
  3. User button-ஐ click செய்ததும் callback function execute ஆகிறது.
  4. Paragraph text update ஆகிறது.
4. Event Object

User ஒரு button-ஐ click செய்யும்போது, அந்த நிகழ்வைப் பற்றிய தகவல்களை Browser ஒரு Event Object மூலம் callback function-க்கு வழங்குகிறது.

HTML 
<button id="clickBtn">Click Me</button>
JavaScript 
const button = document.getElementById("clickBtn");

button.addEventListener("click", function(event) {
    console.log(event);
});

event என்பது Browser callback-க்கு தானாக அனுப்பும் parameter. Parameter name-ஐ நமக்கு விருப்பமான பெயரில் எழுதலாம்: 

button.addEventListener("click", function(e) {
    console.log(e);
});
event மற்றும் e இரண்டும் ஒரே Event Object-ஐக் குறிக்கின்றன.
5. Important Event Object Properties
Property Purpose
event.type எந்த event நடந்தது? (click, input, etc.)
event.target Event முதலில் எந்த element-ல் ஏற்பட்டது?
event.currentTarget Listener attach செய்யப்பட்டுள்ள element எது?
event.clientX Mouse-ன் horizontal viewport position
event.clientY Mouse-ன் vertical viewport position
event.key எந்த keyboard key press செய்யப்பட்டது?
6. event.target vs event.currentTarget

Parent div-ல் event listener register செய்துள்ளோம். அதன் உள்ளே மூன்று child buttons இருக்கின்றன.

HTML Structure 
<div id="parent">
    <button id="btn1">Button 1</button>
    <button id="btn2">Button 2</button>
    <button id="btn3">Button 3</button>
</div>
JavaScript 
const parent = document.getElementById("parent");

parent.addEventListener("click", function(event) {
    console.log("Clicked Element:", event.target.id);
    console.log("Listener Element:", event.currentTarget.id);
});
event.target

Event முதலில் எந்த element-ல் ஏற்பட்டதோ அந்த element. உதாரணமாக, btn2 click செய்தால் event.target.id → "btn2".

event.currentTarget

தற்போது callback execute ஆகும் listener attach செய்யப்பட்ட element. இங்கு parent-ல் listener இருப்பதால் event.currentTarget.id → "parent".

**Quick Revision**
  • DOM: Browser உருவாக்கும் HTML document object structure.
  • Event: User அல்லது Browser நிகழ்த்தும் action/event.
  • addEventListener(): ஒரு element-ல் event-ஐ listen செய்யும்.
  • Event Object: நடந்த event பற்றிய தகவல்களை வழங்கும்.
  • target: Event முதலில் ஏற்பட்ட element.
  • currentTarget: Listener attach செய்யப்பட்ட element.

Event Propagation

1. What is Event Propagation?

ஒரு webpage-ல் nested HTML elements இருக்கின்றன என்று வைத்துக்கொள்வோம். User innermost button-ஐ click செய்யும்போது, Browser அந்த event-ஐ DOM hierarchy வழியாகக் கொண்டு செல்கிறது. இந்த process-தான் Event Propagation. 

<div id="outer">
    <div id="parent">
        <button id="child">Click Me</button>
    </div>
</div>
2. Event Propagation – Three Phases
Phase 1 – Capturing
Outer
↓
Parent
↓
Child
Outside → Inside Event target-ஐ அடைவதற்கு முன் ancestor elements வழியாகப் பயணிக்கும்.
Phase 2 – Target
Child Button
↓
Actual Event Target
Target Element Event உண்மையில் ஏற்பட்ட element-ஐ அடைகிறது.
Phase 3 – Bubbling
Child
↑
Parent
↑
Outer
Inside → Outside Bubbling செய்யக்கூடிய events ancestor elements நோக்கிப் பயணிக்கும்.
3. Understanding Each Phase
Capturing – Parent observes first

Event target-ஐ அடைவதற்கு முன்பே parent அல்லது ancestor elements event-ஐ observe அல்லது handle செய்யலாம்.

Example: Application-level click monitoring.
Target – Actual action

User interaction செய்த element-ஐ event அடைகிறது. அந்த element-ல் register செய்யப்பட்ட listeners execute ஆகலாம்.

Example: Add to Cart button click.
Bubbling – Parent responds afterwards

Event target-ஐ அடைந்த பிறகு, bubbling support செய்யும் event parent மற்றும் ancestor elements நோக்கிப் பயணிக்கும்.

Example: Parent-level click handling.
4. Why is Event Propagation Needed?

Shopping Cart example எடுத்துக்கொள்வோம். மூன்று levels இருக்கின்றன:

<div id="cart">                 <!-- Grandparent -->
    <div id="product">           <!-- Parent -->
        <button id="addToCart">Add to Cart</button>
    </div>
</div>

User Add to Cart button-ஐ click செய்தால், button-ல் மட்டும் event listener இல்லாமல், product மற்றும் cart போன்ற parent elements-ல் உள்ள listeners-ம் அந்த click event-ஐ கவனிக்க முடியும். இதற்குத்தான் Event Propagation உதவுகிறது.

5. Capturing vs Bubbling – Code Example

addEventListener()-ன் மூன்றாவது argument-ல் true அல்லது { capture: true } கொடுத்தால் capturing listener register ஆகும். Default-ஆக listener bubbling phase-ல் செயல்படும். 

const outer = document.getElementById("outer");
const parent = document.getElementById("parent");
const child = document.getElementById("child");

// Capturing listeners
outer.addEventListener("click", () => console.log("Outer Capture"), true);
parent.addEventListener("click", () => console.log("Parent Capture"), true);

// Target listener
child.addEventListener("click", () => console.log("Child Target"));

// Bubbling listeners
parent.addEventListener("click", () => console.log("Parent Bubble"));
outer.addEventListener("click", () => console.log("Outer Bubble"));
**Expected order when Child button is clicked:**
  1. Outer Capture
  2. Parent Capture
  3. Child Target
  4. Parent Bubble
  5. Outer Bubble
6. Event Delegation

Event Delegation என்பது ஒவ்வொரு child element-க்கும் தனித்தனியாக event listener register செய்யாமல், parent element-ல் ஒரே listener register செய்து, bubbling மூலம் child events-ஐ handle செய்யும் technique.

உதாரணமாக, Product List-ல் 100 products இருக்கின்றன என்று வைத்துக்கொள்வோம். 

<ul id="productList">
    <li>Product 1 <button>Add</button></li>
    <li>Product 2 <button>Add</button></li>
    <li>Product 3 <button>Add</button></li>
</ul>
Approach 1 – Individual Listeners ஒவ்வொரு button-க்கும் listener register செய்கிறோம். 
const buttons = document.querySelectorAll(
    "#productList button"
);

buttons.forEach(button => {
    button.addEventListener("click", function() {
        console.log("Product added");
    });
});
100 buttons இருந்தால் 100 listeners தேவைப்படும்.
Approach 2 – Event Delegation Parent-ல் ஒரே listener register செய்கிறோம். 
const productList = document.getElementById("productList");

productList.addEventListener("click", function(event) {

    const button = event.target.closest("button");

    if (button && productList.contains(button)) {
        console.log("Product added");
    }

});
ஒரே parent listener மூலம் எல்லா product buttons-ஐயும் handle செய்யலாம்.
7. How Event Delegation Works
  1. User Product 2-ன் Add button-ஐ click செய்கிறார்.
  2. Event முதலில் அந்த button-ல் ஏற்படுகிறது.
  3. Event parent ul-க்கு bubble ஆகிறது.
  4. Parent-ல் register செய்த listener execute ஆகிறது.
  5. event.target.closest("button") மூலம் click செய்யப்பட்ட button-ஐ கண்டுபிடிக்கிறோம்.
  6. அந்த button product list-க்குள் இருப்பதை உறுதி செய்து action execute செய்கிறோம்.
**Why use closest() instead of matches()?**
  • event.target.matches("button") – Click செய்யப்பட்ட element button-ஆக இருந்தால் மட்டும் match ஆகும்.
  • event.target.closest("button") – Button-க்குள் இருக்கும் icon அல்லது span போன்ற child element click செய்யப்பட்டாலும், அருகிலுள்ள button-ஐ கண்டுபிடிக்கும்.
**Quick Revision**
  • Capturing: Outer → Inner
  • Target: Actual event element
  • Bubbling: Inner → Outer
  • Event Delegation: Parent-ல் ஒரே listener வைத்து child events-ஐ handle செய்வது.

stopPropagation() vs preventDefault()

1. stopPropagation() – Stop Event Propagation

ஒரு Product Card-ல் இரண்டு actions இருக்கின்றன என்று வைத்துக்கொள்வோம்:

  • Card-ஐ click செய்தால் Product Details page திறக்க வேண்டும்.
  • அதற்குள் இருக்கும் Delete button-ஐ click செய்தால் Product delete ஆக வேண்டும்.
  • Delete button click செய்யும்போது Card-ன் click handler execute ஆகக்கூடாது. 
<div id="productCard">
    <h3>Laptop</h3>

    <button id="deleteBtn">
        Delete Product
    </button>
</div>
const card = document.getElementById("productCard");
const deleteBtn = document.getElementById("deleteBtn");

card.addEventListener("click", function() {
    console.log("Opening product details");
});

deleteBtn.addEventListener("click", function(event) {
    console.log("Deleting product");

    event.stopPropagation();
});
**Case 1 – Click Product Card** 
Opening product details
Card listener execute ஆகும்.
**Case 2 – Click Delete Button** 
Deleting product
Delete listener execute ஆகும். Event parent Card-க்கு bubble ஆகாது.
**Why parent listener does not execute?** event.stopPropagation() event தொடர்ந்து ancestor elements-க்கு propagate ஆவதைத் தடுக்கிறது. இதனால் parent Card-ன் bubbling listener execute ஆகாது.
2. preventDefault() – Stop Browser's Default Action

ஒரு Login Form எடுத்துக்கொள்வோம். Form submit செய்யும்போது Browser normally தனது default form submission action-ஐச் செய்கிறது. ஆனால் நாம் JavaScript மூலம் validation செய்து, அதன் பிறகு API request அனுப்ப விரும்புகிறோம். 

<form id="loginForm">
    <input type="email" placeholder="Email">
    <button type="submit">Login</button>
</form>
const loginForm = document.getElementById("loginForm");

loginForm.addEventListener("submit", function(event) {

    event.preventDefault();

    console.log("Handling form submission using JavaScript");

});
**What happens here?**
  • event.preventDefault() – Browser-ன் default form submission-ஐத் தடுக்கிறது.
  • JavaScript callback தொடர்ந்து execute ஆகிறது.
  • இப்போது நாமே form validation மற்றும் API request செய்யலாம்.
3. Common Example – Anchor Link
**HTML** 
<a href="https://example.com"
   id="myLink">
    Visit Website
</a>
**JavaScript** 
const link = document.getElementById("myLink");

link.addEventListener("click", function(event) {

    event.preventDefault();

    console.log("Navigation prevented");

});
Link click செய்தாலும் browser அந்த URL-க்கு navigate ஆகாது.
4. stopPropagation() vs preventDefault()
Method Purpose What does it stop?
stopPropagation() Event propagation-ஐ நிறுத்துகிறது. Event ancestor elements-க்கு தொடர்ந்து propagate ஆவதைத் தடுக்கிறது.
preventDefault() Browser default action-ஐத் தடுக்கிறது. Form submission, link navigation போன்ற default behavior-ஐத் தடுக்கிறது.
**Easy way to remember**
  • stopPropagation() → Stop the event journey.
  • preventDefault() → Stop the browser's default action.
5. Can We Use Both Together?

ஆம்! ஒரே event handler-ல் இரண்டையும் பயன்படுத்தலாம்.

<div id="parent">
    <a href="https://example.com" id="child">
        Click Me
    </a>
</div>
const parent = document.getElementById("parent");
const child = document.getElementById("child");

parent.addEventListener("click", function() {
    console.log("Parent clicked");
});

child.addEventListener("click", function(event) {

    console.log("Child clicked");

    event.preventDefault();
    event.stopPropagation();

});
**Output when user clicks the link:** 
Child clicked
What happened?
  1. preventDefault() – Link navigation-ஐத் தடுத்தது.
  2. stopPropagation() – Parent-க்கு bubbling செல்வதைத் தடுத்தது.
**Important distinction:** stopPropagation() அதே element-ல் register செய்யப்பட்ட மற்ற event listeners-ஐ நிறுத்தாது. அது event propagation-ஐ மட்டுமே நிறுத்துகிறது. preventDefault() event handler execution-ஐ நிறுத்தாது; அது cancel செய்யக்கூடிய browser default action-ஐ மட்டுமே தடுக்கிறது.
**Quick Revision**
  • stopPropagation: Parent / ancestor listeners-க்கு event தொடர்ந்து செல்லாமல் தடுக்கிறது.
  • preventDefault: Browser-ன் default behavior-ஐத் தடுக்கிறது.
  • Both together: Default action-ஐயும் event propagation-ஐயும் தனித்தனியாகத் தடுக்கலாம்.

Event Delegation – Practical Implementation

Shopping Application-ல் products dynamically add செய்யப்படுகின்றன என்று வைத்துக்கொள்வோம். ஒவ்வொரு product button-க்கும் தனித்தனியாக event listener register செய்யாமல், parent element-ல் ஒரே listener பயன்படுத்தலாம்.

1. Complete HTML Structure
<div id="productList">

    <button class="add-btn" data-product-id="1">
        <span>Add Product 1</span>
    </button>

    <button class="add-btn" data-product-id="2">
        <span>Add Product 2</span>
    </button>

    <button class="add-btn" data-product-id="3">
        <span>Add Product 3</span>
    </button>

</div>

<button id="addNewProduct">Add New Product</button>

<p id="message"></p>
2. Complete JavaScript Implementation
const productList = document.getElementById("productList");
const addBtn = document.getElementById("addNewProduct");
const message = document.getElementById("message");

let nextProductId = 4;

// 1. Event Delegation
productList.addEventListener("click", function(event) {

    const button = event.target.closest(".add-btn");

    if (!button || !productList.contains(button)) {
        return;
    }

    const productId = button.dataset.productId;

    console.log("Product added:", productId);

    message.textContent = `Product ${productId} added to cart`;
});

// 2. Dynamic Product Creation
addBtn.addEventListener("click", function() {

    const newButton = document.createElement("button");

    newButton.className = "add-btn";
    newButton.dataset.productId = nextProductId;

    const span = document.createElement("span");
    span.textContent = `Add Product ${nextProductId}`;

    newButton.appendChild(span);
    productList.appendChild(newButton);

    console.log("New product created:", nextProductId);

    nextProductId++;
});
3. What is closest()?

User Add Product 1 என்ற text-ஐ click செய்கிறார் என்று வைத்துக்கொள்வோம். அந்த text ஒரு span element-க்குள் இருக்கிறது.

**HTML** 
<button class="add-btn">
    <span>Add Product 1</span>
</button>
**Check event.target** 
productList.addEventListener("click", function(event) {
    console.log(event.target);
});
Text-ன் உள்ளே இருக்கும் span-ஐ click செய்தால் event.target என்பது span element.

ஆனால் நமக்குத் தேவையானது parent button. அதற்காக closest(".add-btn") பயன்படுத்துகிறோம். 

const button = event.target.closest(".add-btn");
**How closest() works** 1. Clicked element **span** .add-btn? No 2. Parent element **button.add-btn** Selector matched! Returns this button

closest() என்பது தற்போதைய element-லிருந்து ஆரம்பித்து, அதன் parent elements வழியாக மேலே சென்று, கொடுக்கப்பட்ட CSS selector-க்கு match ஆகும் மிக அருகிலுள்ள element-ஐ return செய்கிறது.

4. What if the Button Itself is Clicked?
// If user clicks directly on the button:
event.target = button;

const button = event.target.closest(".add-btn");

closest() முதலில் அந்த button-ஐயே check செய்யும். அது .add-btn selector-க்கு match ஆவதால், அதே button-ஐ return செய்யும்.

5. What if No Matching Element Exists?

.add-btn class இல்லாத element-ஐ click செய்தால், closest() matching element கிடைக்காததால் null return செய்யும். 

if (!button || !productList.contains(button)) {
    return;
}
**Why these two conditions?**
  • !button – Matching .add-btn கிடைக்கவில்லை என்றால் handler-ஐ நிறுத்துகிறது.
  • !productList.contains(button) – கிடைத்த button இந்த productList-க்குள் இருக்கிறதா என்பதை உறுதி செய்கிறது.
6. What is dataset?

HTML-ல் data- என்று தொடங்கும் attributes-ஐ custom data store செய்யப் பயன்படுத்தலாம். JavaScript-ல் Browser வழங்கும் built-in dataset property மூலம் அந்த values-ஐ access செய்யலாம். 

<button class="add-btn" data-product-id="101">
    Add Product
</button>
HTML Attribute JavaScript dataset
data-product-id="101" button.dataset.productId
data-user-name="Raj" button.dataset.userName
data-order-id="500" button.dataset.orderId
**Important – HTML to JavaScript mapping**
  • HTML attribute name-ல் hyphen பயன்படுத்துகிறோம்: data-product-id.
  • JavaScript-ல் camelCase பயன்படுத்துகிறோம்: dataset.productId.
  • dataset Browser வழங்கும் property; நாம் தனியாக create செய்ய வேண்டியதில்லை.
  • Dataset values always strings. Number தேவைப்பட்டால் Number(button.dataset.productId) பயன்படுத்தலாம்.
7. Dynamic Product Creation – How Does It Work?
**Create a new button** 
const newButton = document.createElement("button");

newButton.className = "add-btn";
newButton.dataset.productId = nextProductId;
New button create செய்து class மற்றும் product ID assign செய்கிறோம்.
**Add button to DOM** 
const span = document.createElement("span");

span.textContent = `Add Product ${nextProductId}`;

newButton.appendChild(span);
productList.appendChild(newButton);
Span-ஐ button-க்குள் சேர்த்து, button-ஐ productList-க்குள் சேர்க்கிறோம்.
8. Why Does Event Delegation Work for New Elements?
  1. முதலில் parent productList-ல் ஒரே click listener register செய்கிறோம்.
  2. பிறகு புதிய product button-ஐ dynamically create செய்து DOM-ல் சேர்க்கிறோம்.
  3. New button-ஐ click செய்தால் event parent-க்கு bubble ஆகிறது.
  4. ஏற்கனவே register செய்த parent listener அந்த event-ஐ handle செய்கிறது.
**Quick Revision**
  • event.target: User click செய்த actual element.
  • closest(): Current element அல்லது அதன் ancestors-ல் matching element-ஐத் தேடும்.
  • contains(): ஒரு element மற்றொரு element-க்குள் இருக்கிறதா என்று check செய்யும்.
  • dataset: HTML custom data-* attributes-ஐ JavaScript-ல் access செய்யும்.
  • Event Delegation: Dynamically added child elements-ஐயும் parent listener மூலம் handle செய்யலாம்.

Click on Empty Space – Document-level Event Listener

சில நேரங்களில் webpage-ல் எந்த button அல்லது element-ஐயும் click செய்யாமல், காலியான page area-ஐ user click செய்தாரா என்பதை detect செய்ய வேண்டியிருக்கும். இதற்காக document-level event listener பயன்படுத்தலாம்.

1. Implementation
document.addEventListener("click", function(event) {

    if (
        event.target === document.body ||
        event.target === document.documentElement
    ) {
        console.log("User clicked on empty page space");
    }

});
2. How Does It Work?

document-ல் click listener register செய்துள்ளோம். Click event bubbling மூலம் document வரை வந்ததும், event.target எந்த element என்பதை check செய்கிறோம்.

User action event.target Condition
Button click button False
Heading click h1 / h2 False
Empty body area click body True
Area outside body html True
3. Ensure Body Covers the Viewport

சில நேரங்களில் body முழு viewport-ஐயும் cover செய்யாமல் இருக்கலாம். அப்போது body-க்கு குறைந்தபட்ச viewport height கொடுக்கலாம். 

body {
    min-height: 100vh;
}

100vh என்பது viewport-ன் முழு உயரம். min-height: 100vh மூலம் body குறைந்தபட்சம் viewport உயரம் முழுவதும் இருக்கும்.

**Important:** இந்த approach body அல்லது document element-ல் நேரடியாக target ஆகும் clicks-ஐ மட்டுமே detect செய்கிறது. ஒரு empty div-ன் காலியான பகுதியில் click செய்தால் event.target அந்த div ஆக இருக்கும்; இந்த condition match ஆகாது.
**Quick Revision:** document.addEventListener("click", ...) மூலம் document-level click events-ஐ listen செய்யலாம். event.target body அல்லது html ஆக இருந்தால், user empty page space-ஐ click செய்திருக்கிறார் என்று கண்டறியலாம்.
